# Круг · олимпиадная математика

Статическая библиотека из 57 томов: 9 699 страниц и 8 089 записей в поиске. Все PDF, изображения и данные лежат внутри проекта. Для чтения и поиска серверная база, аккаунт и интернет не нужны.

## Открыть на своём компьютере

На Mac дважды нажмите **Открыть сайт.command**. Пока окно запуска открыто, сайт работает по адресу [127.0.0.1:8780](http://127.0.0.1:8780/). Если он уже запущен, откроется работающий сайт. Нужен Python 3; вместо двойного щелчка можно запустить из папки проекта `python3 serve.py --open`. Без сервера можно читать книги через `dist/contents.html` — поиск задач требует запуска сайта.

## Опубликовать на GitHub Pages

1. Откройте папку **krug-site** в GitHub Desktop как локальный репозиторий. Если вы начали с ZIP и GitHub Desktop не находит репозиторий, создайте Git-репозиторий в этой же распакованной папке. Сделайте первый коммит со всеми файлами.
2. Нажмите **Publish repository**. Для GitHub Pages на бесплатном тарифе нужен публичный репозиторий. В книгах сохранены сторонние олимпиадные материалы и ссылки на источники; перед публичной публикацией проверьте, что материалы можно разместить открыто.
3. В репозитории на GitHub откройте **Settings → Pages → Source → GitHub Actions**.
4. Откройте **Actions → Опубликовать библиотеку → Run workflow**, выберите ветку `main` и запустите. После успешного выполнения адрес появится в **Settings → Pages**. При обновлениях сначала отправьте коммит, затем повторно запустите этот процесс.

Рабочий процесс размещает только папку `dist`. Около 532 МБ сайта помещаются в лимит GitHub Pages 1 ГБ. Отдельное хранилище для книг и Git LFS не нужны. Используйте GitHub Desktop или Git: некоторые PDF превышают лимит загрузки через браузер (25 МиБ).

## Что в папках

- `dist/index.html` — главная и все тома; `tasks.html` — поиск; `reader.html` — чтение и скачивание; `contents.html` — прямые ссылки.
- `dist/books/` — 57 томов и PDF-путеводитель. Имена файлов сохранены для переходов между книгами.
- `dist/catalog/` — оглавление и индекс задач с переходами на страницы.
- `dist/assets/` — оформление, иллюстрация и код сайта.
- `.github/workflows/pages.yml` — подготовленная публикация.
- `tools/` — обновление данных и проверка комплекта. Для публикации ничего пересобирать не нужно.

Для проверки комплекта выполните `python3 tools/check_site.py`. Для обновления из нового издания можно использовать `tools/build_catalog.py` и `tools/compact.py`; исходный каталог книг должен содержать `manifest.json`, `catalogue.json` и PDF. Скрипт сжатия использует PyMuPDF и оставляет оригинал, если сравнение выявляет различие.

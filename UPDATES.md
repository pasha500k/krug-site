# Олимпиады, вступительные и автономная библиотека

- **Олимпиады**: поиск по полным названиям и сокращениям, годам, классам и языкам. Выберите «Материалы» у организатора, чтобы увидеть найденные официальные варианты. Если вариантов в указателе ещё нет, используйте ссылку «Архив». Университетские архивы включают «Покори Воробьёвы горы!», олимпиаду СПбГУ и «Бельчонок» СФУ. В каталоге также есть Всесибирская олимпиада НГУ, олимпиады Шарыгина, RMM и архивы Канадского математического общества и UKMT. Если организатор опубликовал комплект в ZIP, карточка ведёт к официальному скачиванию.
- **Поступление**: официальные архивы СУНЦ МГУ, ФМЛ № 239 и Лицея НИУ ВШЭ и ссылка на официальный раздел поступления «Летово». Для открытия материалов школ нужен интернет.
- **Задачи**: запросы можно комбинировать, например `ВсОШ 2025 треугольник` или `тургор чётность`. Для класса и года есть точные фильтры. Годы и классы дополняются по заголовкам, датам тура и обозначениям в источнике. Неуказанные классы остаются пустыми.
- **Без интернета**: пока есть соединение, нажмите «Сохранить указатель» на главной. В томах нажмите «Сохранить для офлайна». Кэш принадлежит браузеру и адресу сайта; повторное сохранение использует существующую копию. Для хранения вне браузера скачайте PDF обычной кнопкой. При очистке данных браузера офлайн-кэш удалится.
- **Язык**: Auto использует языковые настройки браузера, RU и EN переключают интерфейс вручную. При равном годе каталоги показывают выше PDF на предпочитаемом языке, если версия опубликована организатором. Условия, разборы и PDF без такой версии остаются на исходном языке.

## Проверка обновлений на Mac

В основной папке `Olypiads` откройте **Проверять обновления.command**. Панель доступна по [127.0.0.1:8781](http://127.0.0.1:8781/). Один процесс выполняет проверку сразу и затем каждые 12 часов, пока запущен. Для изменения периода укажите `--hours`:

```bash
.venv/bin/python -m olympiad_collector.archive_watch --hours 12 --pages 8
```

Для разовой проверки добавьте `--once` вместо запуска панели. Запускать второй экземпляр параллельно не нужно. Настройка `--pages` ограничивает число проверяемых страниц на источник, а панель отмечает достигнутые лимиты и ошибки. Проверка обновляет ссылки в `krug-site/dist/catalog/archives.json`, не загружая PDF. Она сохраняет предыдущие найденные материалы, если источник временно не отвечает.

Для скачивания и разметки документов используется исходная программа сбора. Она проверяет наличие локального файла по адресу и хранит PDF и ZIP по хешу содержимого. Повторная обработка использует сохранённые файлы. `--refresh` явно запрашивает повторное получение материала.

## Обновление публичного сайта

GitHub Pages размещает готовые статические файлы. После локальной проверки добавьте изменённый `dist/catalog/archives.json` и остальные изменения сайта в коммит, отправьте его на GitHub и запустите **Опубликовать библиотеку** в Actions. Панель проверки остаётся на вашем компьютере.

Если обновляете основное издание книг, сначала заново экспортируйте указатель из снимка, затем запустите `krug-site/tools/enrich_catalog.py` тем же Python, которым работает сборщик. Он дополняет уже существующие записи сайта из локальной базы, сохраняя номера задач и ссылки на страницы.

## Просмотр официальных документов

Кнопка «Открыть на сайте» в каталогах открывает читалку «Круга». Для 918 документов, уже включённых в тома, она сразу открывает нужную страницу; эти тома можно сохранить в браузере для офлайна. Другие материалы олимпиад могут загружаться в читалку с официального сайта организатора. В публичном разделе поступления документы открываются по ссылкам на сайты школ. Если источник запрещает показ в рамке, требует входа или недоступен, используйте «Оригинал у источника».

После замены издания книг обновите карту документов командой `python3 krug-site/tools/build_document_links.py` из основной папки `Olypiads`.

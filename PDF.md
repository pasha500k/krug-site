# Оригиналы и перевод PDF

Откройте вариант из раздела «Олимпиады» или «Поступление» через «Открыть на сайте». В читалке есть поле **Язык PDF**. При открытии оно подставляет язык браузера или выбранный язык сайта. Пункт «Оригинал» возвращает неизменённый PDF.

- Если организатор выпустил нужную языковую версию того же комплекта (в частности, для IMO и EGMO), открывается она.
- Иначе локальный сервер переводит извлекаемый текст между русским и английским прямо на исходных страницах. Готовый PDF хранится на диске и используется повторно. Во время обработки можно читать оригинал.
- Формулы, графика и нумерация остаются на исходных страницах. Если текст скана или строки с формулой нельзя безопасно заменить, читалка сообщает о неполном переводе или показывает оригинал. Организатор и источник указаны в читалке и метаданных PDF. В локальном рабочем архиве есть вычитанная версия работы ФМЛ № 239 для 10 класса от 19.04.2026 с сохранёнными реквизитами.
- Нажмите «Сохранить для офлайна» после открытия нужной версии. Это сохраняет выбранный оригинал или перевод в кэше браузера.

## Фоновый перевод

Локальный сайт начинает перевод автоматически при запуске, даже если закрыть вкладку. Каталог обрабатывается порциями, PDF — по одному. PDF, открытый в читалке, может переводиться отдельно от фоновой очереди. На страницах сайта видны счётчики готовых материалов. Карточки задач показывают готовый текст на языке интерфейса и постепенно обновляются.

Готовые результаты сохраняются в `data/translated/`. После перезапуска сервер пропускает уже проверенные материалы. Когда локальный архив пополняется, новые файлы попадают в следующую проверку. Для запуска без фоновой обработки используйте `python3 serve.py --no-background-translation`.

Перевод работает между русским и английским. Для смешанных строк переводятся слова исходного языка, а обозначения переменных и формулы остаются на странице. Скан без текстового слоя может остаться в оригинале. Документы с режимом «только официальная страница» исключены из очереди.

## На этом Mac

Запуск сайта: **Открыть сайт.command** в папке `krug-site`. Модели и файлы уже установлены локально. Оригиналы лежат в `Olypiads/data/files/`, список источников — в `Olypiads/data/mirror.json`, переводы — в `Olypiads/data/translated/`.

Из основной папки `Olypiads` можно дополнить локальный архив:

```bash
.venv/bin/python -m olympiad_collector.mirror
```

Повторный запуск переиспользует сохранённые файлы. Ошибки видны в `data/mirror-errors.json`. Для регулярной проверки и скачивания новых PDF запустите **Проверять обновления.command**. Если прежняя панель уже запущена, сначала завершите её процесс, чтобы не запускать две проверки одновременно.

## На GitHub Pages

Публичная статическая версия использует тома и официальные языковые версии. Локальные оригиналы, модели и машинные переводы находятся вне публикуемой папки `dist`. Для автоматической генерации на публичном сайте понадобится сервер перевода. Для вступительных испытаний публичный каталог ведёт на сайты школ. Для «Летово» локальная и публичная версии показывают только ссылку на официальный раздел поступления. Текущий статус указан на [странице разрешений школ](dist/permissions.html).

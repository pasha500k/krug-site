# Выбор класса в архиве и читалке — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Цель** — по карточке найти задания своего класса и открыть один и тот же раздел документа в читалке и у организатора.

**Архитектура** — общий модуль вычисляет соответствие фильтру, класс для заголовка и страницу документа. Каталог строит карточки и ссылки, а читалка применяет результат к оригиналу, локальной копии или странице тома.

**Стек** — статический HTML, CSS и JavaScript, Python для проверки комплекта сайта, Playwright для браузерной приёмки, GitHub Pages для публикации.

**Спецификация** — [GitHub Issue № 1](https://github.com/pasha500k/krug-site/issues/1).

## Общие ограничения

- Один документ представлен одной карточкой. В крупном заголовке сначала название олимпиады, затем класс или диапазон.
- При известной начальной странице выбранного класса обе ссылки ведут к ней. Без выбора класса или без известной страницы документ открывается с начала.
- Сохраняются форматы записей каталога и адресов читалки. «Скачать ZIP» ведёт к архиву организатора без фрагмента с именем вложения.
- Новые источники, распознавание недостающих страниц, перевод PDF и тренировки находятся вне объёма Issue № 1.

## Текущее состояние

Модуль `archiveClass` и его вызовы уже есть в локальных изменениях. Пройдены 42 теста Python, проверка комплекта и браузерные сценарии без фильтра, с 10-м классом и с исключением карточки для 8-го класса. Начать с дополнительной приёмки. Исправлять только расхождения, подтверждённые проверками. В рабочей копии также есть изменения каталога и Рптренировки из других задач.

## Особые случаи для приёмки

1. Класс в поисковом запросе даёт те же заголовок и страницу, что и явный фильтр.
2. При частичной разметке PDF класс, входящий в явно указанный диапазон, остаётся доступным в фильтре. Если его страница неизвестна, показывается диапазон и открывается начало PDF.
3. Без сведений о классе заголовок содержит название олимпиады, а карточка доступна без фильтра по классу.
4. Переключение класса в читалке обновляет страницу, на которую ведёт «Оригинал».
5. Для вложения в ZIP ссылка содержит адрес архива без фрагмента с именем PDF.

### Задача 1. Подтвердить поведение каталога и читалки

**Файлы** — `dist/assets/site.js` содержит общий модуль и читалку, `dist/assets/archive.js` отвечает за фильтр и карточки, `dist/sw.js` обновляет кэш статического сайта при изменении этих ресурсов. Существующий временный сценарий `../tmp/check-archive-class.mjs` проверяет страницы через браузер.

**Интерфейс** — `archiveClass(item, requestedGrade)` принимает запись с необязательными `grade` и `gradePages` и строку класса либо пустое значение. Возвращает `matches` (логическое значение), `selected` и `labelGrade` (строки), `page` (номер страницы или 0 для открытия с начала) и `pageGrades` (массив классов с известными страницами). Каталог и читалка потребляют один результат.

- [ ] **Расширить браузерную приёмку.** Сохранить действующие проверки и добавить следующие сценарии. Для частичной разметки в отдельном браузерном контексте подменить ответ `catalog/archives.json`, оставив у документа ВсОШ диапазон `9–11` и только страницу 1 для 9-го класса. Данные сайта на диске сохраняются.

  | Вход | Проверяемый результат |
  |---|---|
  | ВсОШ, 2026, второй день региона, без фильтра | Одна карточка «ВсОШ · 9–11 классы». Обе ссылки открывают начало |
  | Тот же PDF, класс 9 или 10 | «ВсОШ · 9 класс» и `#page=1` либо «ВсОШ · 10 класс» и `#page=3`. Ниже видны 2026, русский язык, региональный этап и второй день |
  | Тот же PDF, класс 8 | Карточки нет |
  | Запрос «ВсОШ 2025/26 10 класс 2-й день регион» | Та же карточка и `#page=3`, что и у фильтра 10-го класса |
  | Финал ВсОШ 2021, день 1, фильтр 10-го класса | «ВсОШ · 9–11 классы». Обе ссылки открывают начало |
  | Подменённая частичная разметка, фильтр 10-го класса | Карточка «ВсОШ · 9–11 классы». Обе ссылки открывают начало |
  | В читалке ВсОШ 2026 переключиться с 10-го на 9-й класс | «Оригинал» меняется с `#page=3` на `#page=1` |
  | Весенний сложный вариант Турнира городов 2026, без фильтра | Заголовок «Турнир городов», без класса |
  | Ломоносов 2026, 11-й класс, отборочный этап | «Ломоносов · 11 класс». «Скачать ZIP» ведёт к математическому архиву МГУ без `#member=` |

- [ ] **Запустить сценарии.** Из корня `Olypiads` выполнить `node tmp/check-archive-class.mjs` при работающем локальном сайте. В читалке проверять ссылку «Оригинал» после перехода из карточки. В частичном сценарии текущая реализация, вероятно, скроет карточку, поскольку отдаёт приоритет списку классов с размеченными страницами.

Выбор конкретной страницы по-прежнему требует положительного номера в `gradePages`. Сохранить заголовок с диапазоном при неизвестной странице. Проверить реальные записи, у которых список страниц расходится с указанным диапазоном. Если данные источника противоречат друг другу, зафиксировать конкретный пример отдельно от приёмки навигации.
